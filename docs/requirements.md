# Veritas Product Requirements

Source: `/home/ubuntu/upload/Document_Merged.pdf` (117 pages, text-based PDF; full text was scanned during planning).

## Product

An interactive mobile application for investigative journalists: a secure investigative intelligence hub for researching, visualizing, verifying, and collaborating around a case.

## Core surfaces

1. **Home Dashboard** — global investigation map, case entities/relationships, quick actions, AI-assisted live feed, and encryption/anonymity status.
2. **Case Workspace / Evidence Vault** — encrypted evidence repository for PDFs, reports, FOIA responses, contracts, images, screenshots, audio, video, notes, and metadata; viewer, annotations, entity links, timeline reconstruction, tags, cross-links, version history, and secure sharing.
3. **Analysis Mode / Pattern Finder** — recurring names/entities, repeated financial transactions, shared metadata, coordinated timing, overlapping locations, spikes/gaps, entity clustering, temporal analysis, metadata correlation, financial trails, communication graphing, network view, heatmap, timeline overlay, anomaly alerts, filters, and insight cards with confidence scores.
4. **Collaboration Hub** — secure contextual chat, team board, assignments, verification status, granular roles for editors/analysts/contributors, and immutable-style audit trail.
5. **Investigative Copilot** — document summarization, source verification, lead generation, pattern recognition, ethical guidance, chat, voice-command mode, contextual suggestions, encrypted-context operation, and auditability.

## Ethical Source Checker

When evidence is uploaded, check source authenticity, license compliance, consent, and tampering indicators. Return a credibility score and status badge: green verified, yellow uncertain, or red restricted. Provide a traceability report, chain of custody, license type, suggested open-access alternatives, and manual-review prompts. Support AI-assisted redaction.

## Security and ethics

The source describes end-to-end encryption, anonymous collaboration channels, zero-knowledge storage, MFA, tamper detection, immutable audit logs, and a human-judgment-first AI posture. The prototype must label these as future production integrations unless actually implemented.

## Visual direction

Dark-mode neon aesthetic, holographic overlays for data visualization, gesture-friendly navigation, adaptive research/presentation typography, and a calm professional copilot.
