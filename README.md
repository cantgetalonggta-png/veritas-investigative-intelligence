# Veritas Investigative Intelligence

Autonomous multi-node public research engine for investigative journalism.

## Live multi-node search
- Wikidata
- SEC EDGAR
- GDELT News
- Wikipedia
- OpenAlex

## Run locally
```bash
npm install
npm run dev
```

## Deploy
Connected to Vercel for production.

Public research results are **lead lists**, not findings. Always verify sources.
